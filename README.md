 # FarmFlow: Livestock Management System

## Description

FarmFlow is a modern, professional, and secure Livestock Management System built entirely with **HTML, CSS, and Vanilla JavaScript**. It solves a real-world problem by helping farmers efficiently manage their livestock, track animal health, and monitor all financial activities. The system is a client-side application that features a secure login and uses **LocalStorage** to persist all farm data directly in the user's browser.

## ✨ Key Features

- **Secure Login System**: Access to the system is protected by a username and password. The session is managed via `sessionStorage`.
- **Comprehensive Dashboard**: At a glance, view key metrics like total animals, health status, and a full financial summary (income, expenses, net profit).
- **Full Livestock Management**: Complete **CRUD** (Create, Read, Update, Delete) functionality for all animal records.
- **Advanced Filtering & Search**: Instantly find animals by type or breed, and filter them by health status.
- **Detailed Financial Tracking**: Log all income (e.g., milk sales) and expenses (e.g., feed, medicine) with ease.
- **Automatic Calculations**: The system automatically calculates total income, expenses, and net profit across the application.
- **Persistent Data Storage**: All your data is safely stored in your browser's `LocalStorage`, ensuring nothing is lost on page refresh.
- **Modern & Responsive UI**: A clean, farm-themed interface that works beautifully on desktops, tablets, and mobile phones.
- **Light/Dark Mode**: A theme toggler for comfortable viewing in any lighting condition.

## 🛠️ Technologies Used

- **HTML5**: For semantic structure.
- **CSS**: For all styling, responsiveness (Flexbox/Grid), and modern design.
- **JavaScript **: For all application logic, including authentication, DOM manipulation, and data management.

2.  Open the **`index.html`** file in your web browser.
3.  Log in using the following credentials:
    - **Username:** `admin`
